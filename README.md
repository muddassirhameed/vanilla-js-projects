## Projects

### 1. Password Generator

A modern and responsive password generator built with HTML, CSS, and Vanilla JavaScript.

#### Features

- Generate secure random passwords
- Adjustable password length (1–50 characters)
- Password strength indicator (Weak, Average, Strong)
- Copy password to clipboard
- Regenerate password instantly
- Toast notifications for user actions
- Mobile-friendly responsive design
- Clean and modern user interface
